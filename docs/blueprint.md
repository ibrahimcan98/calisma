# **App Name**: FinTrack Personal

## Core Features:

- Manual Income/Expense Entry: Allows users to manually input their income and expenses.
- Date-Based Recording: Records all income and expenses with specific dates for tracking.
- Categorization of Transactions: Enable categorize transactions and optionally assign subcategories. Ability to create categories on the fly.
- Recurring Expenses Management: Supports tracking and managing recurring expenses like subscriptions within categories.
- Financial Overview (Monthly/Weekly): Provides a view of finances broken down by month and week.
- Expenditure Analysis: Generate visualizations of spending by category over time. Suggest ways to improve spending.

## Style Guidelines:

- Primary color: A calming blue (#64B5F6) to instill a sense of financial security and trust.
- Background color: Light, desaturated blue (#E3F2FD), creating a clean and unobtrusive backdrop.
- Accent color: Analogous teal (#4DB6AC), slightly more saturated, for interactive elements and key calls to action.
- Font: 'Inter', a sans-serif font, will be used for both body and headlines for its modern and readable design.
- A clean, minimalistic layout emphasizing ease of data entry and clarity of financial information.
- Use simple, intuitive icons for transaction categories, using a consistent style.
- Subtle transitions for displaying financial data and interactive elements.
